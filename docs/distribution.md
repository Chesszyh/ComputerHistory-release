# 下载、安装和升级

从 [GitHub Releases](https://github.com/Chesszyh/ComputerHistory-release/releases/latest) 下载 Apple Silicon 压缩包。运行要求以 `Package.swift` 为准；源码构建入口见 [README](../README.md)。

## 安装与首次启动

解压后在终端执行 `python3 manage-install.py install`。安装器需要 Python 3，将应用固定安装到 `~/Applications/ComputerHistory.app`。随后在 Finder 中双击该应用；程序本身不需要 Python 或 Swift 工具链。

首次启动会打开独立的授权引导窗口；正文较长时可滚动，底部操作保持可见。关闭窗口不停止后台记录，点击“完成”后后续启动不再自动弹出。也可随时从设置的“授权”页面检查或恢复权限：

- **辅助功能**用于读取应用界面和交互对象。
- **输入监控**用于记录按键、点击和滚动。
- **屏幕录制**仅在启用窗口文字识别时需要。

点击“前往授权”会请求相应权限、打开对应系统设置，并在 Finder 中定位应用。完成后点击“重新检查”。界面同时显示后台采集器的实际输入监听状态；系统预检通过不等于后台已经收到事件。辅助功能和输入监控就绪后，可点击“开始记录”；采集由独立的后台服务管理。权限撤销或更新后，必要时退出并重开应用及采集器。

模型服务在模型设置中单独配置；模型密钥异常时，点击“恢复密钥访问”，按系统要求验证即可。恢复时选择“始终允许”。应用会用新的后台进程确认读取权限，再请求重新生成，无需查找隐藏路径或运行恢复命令。

公开下载是否经过 Developer ID 签名和公证，以该次 Release 说明为准。本机持久签名不能代替面向其他用户的 Developer ID。未公证的包首次运行可能被 Gatekeeper 阻止；确认来源后按 [Apple 的逐程序打开流程](https://support.apple.com/102445)处理。安装器不关闭 Gatekeeper，也不移除下载隔离属性。

## 升级

在新解压目录再次执行 `python3 manage-install.py install`。安装器验证程序签名，停止身份可验证的旧实例，暂存新应用并切换目录，同时更新已有菜单栏和采集器服务的程序路径。已加载的服务会恢复；首次安装不会自动开始采集。失败时恢复旧应用和服务配置，恢复失败会明确报错。

密钥由独立的 `computer-history-credentials` 助手访问。普通升级会保留已安装助手。证书签名版本验证签名身份与协议；两个临时签名版本之间则验证已安装应用的完整签名、助手标识与协议，保留助手后更新临时签名封口，避免本机自签名构建的内容指纹变化导致重复授权。助手协议变化时升级会中止，需显式安排密钥迁移。手动覆盖整个 `.app` 不执行此保留流程；开发构建也应通过安装器更新运行实例。

升级保留 `~/.computer-history` 的历史、配置、请求记录以及钥匙串条目。旧版从构建目录运行的服务会迁移到应用内的固定路径；旧文件不会自动删除。自定义数据目录使用 `--out /你的数据目录`。无法验证身份的旧实例或其他数据目录中的实例须先停止。

首次改用独立密钥助手时，现有钥匙串条目可能要求一次系统确认；后续普通业务更新保留同一助手。系统锁定、主动撤销授权、签名身份或助手协议变更仍可能要求重新验证。

## 命令行与卸载

命令行程序位于 `~/Applications/ComputerHistory.app/Contents/MacOS/`，菜单栏、采集命令和密钥助手应一起安装。权限检查使用 `computer-history --check`，实际运行检查使用 `computer-history --status`；后者包括后台输入监听状态。模型外发边界见 [隐私说明](privacy.md)。

卸载应用与服务并保留历史、配置和钥匙串：

```bash
python3 ~/Applications/ComputerHistory.app/Contents/Resources/manage-install.py uninstall
```

如需移除密钥，先在模型设置中移除已保存的密钥；卸载后再自行清理明确选定的数据目录。

## 构建签名与公证

`scripts/bundle-app.py` 将已构建的三个程序封装为应用。本机使用已有持久签名；正式分发可设置 `CODESIGN_IDENTITY` 为 Developer ID，打包脚本支持通过 `NOTARY_PROFILE` 使用已经配置的公证凭据提交并装订票据。没有提供相应身份或凭据时，不会宣称已完成 Developer ID 签名或公证。
