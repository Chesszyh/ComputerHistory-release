# 隐私与安全边界

本工具读取前台应用内容并在本机保存明文。请只在你有权记录的设备和内容范围内使用，并先用非敏感窗口检查效果。

## 会保存什么

窗口标题、应用信息、可读取的 URL、辅助功能树文本、聚焦控件值和输入变化可能进入事件文件。显式启用 `windowTextApplications` 后，指定前台应用缺少辅助功能正文时还会在本机读取单个窗口图像并识别文字；不保存截图，识别文本会进入事件文件和后续总结材料。配置、权限与系统版本要求见[窗口文字识别说明](collector.md#采集行为与局限)。密码、聊天、令牌或其他敏感内容如果出现在普通文本控件中，也可能被保存。原生密码控件的个别观察不能推广为所有应用或网页密码框的安全保证。

应用与域名策略限制采集，但默认名单有限；身份缺失时的默认拒绝规则见[采集配置](collector.md#配置)。没有完整的隐私浏览检测。界面节点哈希和文本差分不是安全隔离机制。

暂停清除输入基线，恢复后仍可读取当前界面。`COMPUTER_HISTORY_DEBUG_TEXT=1` 会把允许采集的聚焦值片段写进日志，排错时同样应使用非敏感内容。

## 什么时候联网

| 入口 | 网络行为 |
|---|---|
| `collect`、状态及权限检查、菜单栏定时刷新 | 不调用模型 API（应用程序接口） |
| 设置页“从服务获取模型” | 向所选服务读取模型与能力列表；需要时携带该组密钥，不发送活动记录或提示词 |
| `memorize` | 配置了服务且未指定 `--no-model` 时调用模型 |
| `narrative` | 同上，发送已有记忆的摘要内容 |
| `supervise` | 默认周期执行生成任务及已启用的备份；继承启动时的环境变量 |
| `report` | 未指定 `--no-model` 时发送活动正文或日报给配置的模型 |
| `export`、复制材料 | 不调用模型；剪贴板与导出文件保留文本副本 |
| `backup` | 仅配置并启用时向 GitHub 私有数据仓库上传整理后的文本，详见[备份范围](collector.md#报告导出与备份) |

十分钟记忆提示词可包含应用名称、窗口标题、访问地址、输入文本片段、界面内容、点击目标和此前记忆。六小时汇总与叙述会发送已有记忆的部分内容；日报发送活动正文，周报发送日报。截断不是脱敏；要求模型不要复述敏感内容也不等于阻止敏感内容外发。

模型地址和模型名从 `model.json` 或环境读取；远端自托管模型也会收到这些材料。选择备用模型组（或旧配置的 `fallback`）时，仅在主请求失败或输出不可用后，把相同输入发送给降级模型；各次尝试分别保存。每组使用独立密钥，关闭备用后不再发起新的备用请求。需要密钥时优先使用该数据目录下该组在 macOS 钥匙串中保存的密钥，其次按[模型配置规则](collector.md#模型与用量配置)读取环境变量，通过 Authorization 请求头发送；无密钥模式不读取或携带其他服务的凭据。菜单栏输入的新密钥保存在钥匙串，移除数据目录不会自动删除该钥匙串项目，可在模型设置中移除已保存的密钥。自定义服务地址应由使用者确认可信。模型生成和模型列表默认要求远端地址使用 HTTPS；`localhost`、`127.0.0.1`、`::1` 允许本机 HTTP。局域网等远端 HTTP 需在对应模型组显式开启 `allowInsecureHTTP`，这会以明文发送活动材料及该服务密钥，网络上的其他参与者可能读取它们。主模型和备用模型分别校验；模型请求不自动跟随重定向，应填写最终接口地址。HTTPS 保护传输，不代表活动内容已经脱敏，也不限制服务端如何处理收到的材料。不要把密钥写入源码、截图、问题反馈或配置示例。

需要完全禁止模型请求时，对生成入口或监督入口使用 `--no-model`。GitHub 备份有独立的启用开关，默认关闭；`--no-model` 不关闭已启用的备份。关闭总结开关限制新任务排队，不能撤回已发送的请求，也不会立即取消已经排队的任务。

## 数据保存与删除

默认目录是 `~/.computer-history`，CLI 可指定其他目录。段、记忆、叙述、日志及备份均可能含敏感内容；项目未实现应用层加密。新事件段目录限制为当前用户访问，但派生文件权限仍受父目录和系统创建权限影响，请保护整个数据目录。

自动保留策略仅清理可识别的事件段，压缩文件与未压缩文件使用相同策略。记忆中的时序摘录、叙述、请求详情、日志、手动导出、剪贴板和备份具有独立生命周期。请求详情包含实际发送的提示词和模型返回正文，也可能包含敏感信息；不会保存 Authorization 请求头。删除原始段不会删除这些副本，也不会删除已交给外部服务的内容。

清除数据前先停止相应目录的采集器、等待监督退出，并退出菜单栏程序；随后核对数据目录和自行制作的备份再删除。系统回收站、磁盘快照及外部服务副本需要分别处理。

## 反馈问题

公开反馈请只附合成复现数据。不要附原始 `events.jsonl`、个人记忆、完整日志、真实窗口截图或密钥。报告安全问题见 [SECURITY.md](../SECURITY.md)。

## ActivityWatch

[可选 ActivityWatch 接入](collector.md#activitywatch-补充来源)只读访问本机服务。通过应用、网址屏蔽规则的窗口标题、网址、空闲状态与来源信息会随事件明文保存在本项目数据目录，并可进入后续总结及已启用的备份。关闭接入不删除已保存的记录；本项目不会修改或删除 ActivityWatch 自己的数据。
