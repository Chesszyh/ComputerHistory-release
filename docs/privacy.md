# 隐私与安全边界

本工具读取前台应用内容并在本机保存明文。请只在你有权记录的设备和内容范围内使用，并先用非敏感窗口检查效果。

## 会保存什么

窗口标题、应用信息、可读取的 URL、辅助功能树文本、聚焦控件值和输入变化可能进入事件文件。密码、聊天、令牌或其他敏感内容如果出现在普通文本控件中，也可能被保存。原生密码控件的个别观察不能推广为所有应用或网页密码框的安全保证。

应用与域名策略限制采集，但默认名单有限；缺失 URL 时域名匹配不生效，也没有完整的隐私浏览检测。界面节点哈希和文本差分不是安全隔离机制。

暂停清除输入基线，恢复后仍可读取当前界面。`COMPUTER_HISTORY_DEBUG_TEXT=1` 会把允许采集的聚焦值片段写进日志，排错时同样应使用非敏感内容。

## 什么时候联网

| 入口 | 网络行为 |
|---|---|
| `collect`、状态及权限检查、菜单栏读取 | 不调用模型 API（应用程序接口） |
| `memorize` | 有密钥且未指定 `--no-model` 时调用模型 |
| `narrative` | 同上，发送已有记忆的摘要内容 |
| `supervise` | 默认周期执行生成任务；继承启动时的环境变量 |

十分钟记忆提示词可包含应用名称、窗口标题、访问地址、输入文本片段和此前记忆。六小时汇总与叙述会发送已有记忆的部分内容。截断不是脱敏；要求模型不要复述敏感内容也不等于阻止敏感内容外发。

模型地址和模型名从环境读取，密钥通过 Authorization 请求头发送。自定义服务地址应由使用者确认可信；当前客户端不强制 HTTPS。不要把密钥写入源码、截图、问题反馈或配置示例。

需要完全禁止模型请求时，对生成入口或监督入口使用 `--no-model`。关闭总结开关限制新任务排队，不能撤回已发送的请求，也不会立即取消已经排队的任务。

## 数据保存与删除

默认目录是 `~/.computer-history`，CLI 可指定其他目录。段、记忆、叙述、日志及备份均可能含敏感内容；项目未实现应用层加密。新事件段目录限制为当前用户访问，但派生文件权限仍受父目录和系统创建权限影响，请保护整个数据目录。

自动保留策略仅清理可识别的事件段。记忆、叙述、日志、手动导出、剪贴板和备份具有独立生命周期。删除原始段不会删除这些副本，也不会删除已交给外部服务的内容。

清除数据前先停止相应目录的采集器、等待监督退出，并退出菜单栏程序；随后核对数据目录和自行制作的备份再删除。系统回收站、磁盘快照及外部服务副本需要分别处理。

## 反馈问题

公开反馈请只附合成复现数据。不要附原始 `events.jsonl`、个人记忆、完整日志、真实窗口截图或密钥。报告安全问题见 [SECURITY.md](../SECURITY.md)。
